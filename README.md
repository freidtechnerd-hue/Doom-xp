# DOOM XP

A lightweight Windows XP-compatible build of the original open-source DOOM engine, compiled using Open Watcom.

> **Project Status:** Experimental

---

## About

DOOM XP is an experimental build of the original open-source DOOM engine targeting Microsoft Windows XP. The goal of this project is to create a simple executable that runs on older hardware and operating systems using the Open Watcom compiler.

This project is intended as a learning exercise and proof of concept for building classic software with older development tools.

---

## Features

- Windows XP compatible
- Compiled with Open Watcom
- Lightweight executable
- Based on the original open-source DOOM source code
- Designed for older PCs

---

## Current Limitations

This project is still a work in progress.

Known issues include:

- ❌ Wall textures are currently rendered incorrectly.
- ❌ Audio is not yet working.
- ⚠ Additional bugs and graphical issues may be present.

Contributions and bug reports are welcome.

---

## Building

DOOM XP was compiled using **Open Watcom** from the original open-source DOOM source code after making changes to improve compatibility with Windows XP and the Open Watcom toolchain.

General build process:

1. Obtain the original DOOM source code.
2. Apply the DOOM XP modifications.
3. Build the project using Open Watcom.
4. Run the generated executable on Windows XP.

---

## Requirements

- Windows XP (Service Pack 3 recommended)
- A DOOM IWAD (`DOOM.WAD`, `DOOM2.WAD`, etc.)
