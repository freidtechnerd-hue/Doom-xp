## About

DOOM XP is an experimental Windows XP-compatible port of the original
open-source DOOM engine. It was compiled from the original DOOM source code
using **Open Watcom**.

The goal of this project is to create a lightweight DOOM port that can run on
older computers and operating systems while using classic development tools.

---

## Features

- ✅ Windows XP compatible
- ✅ Compiled with Open Watcom
- ✅ Lightweight executable
- ✅ Based on the original DOOM source code
- ✅ Designed for older hardware

---

## Current Issues

This project is currently experimental.

Known problems:

- ❌ Wall textures are currently broken
- ❌ No audio support yet
- ⚠ More bugs may exist

---

## Building

DOOM XP was created by taking the original open-source DOOM source code and
compiling it with the **Open Watcom compiler**.

Build process:

1. Get the original DOOM source code.
2. Apply DOOM XP changes.
3. Compile using Open Watcom.
4. Run the generated executable.

---

## Requirements

- Windows XP SP3 or newer
- DOOM IWAD file (`DOOM.WAD` or `DOOM2.WAD`)
